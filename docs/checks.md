# Проверка лабораторной №5

Дата: 01.11.2026. Среда локальной проверки: Windows, Python 3.12.14,
Tcl/Tk 8.6.12.

## Автоматические проверки

- `unittest`: 31 тест, все прошли; пропусков нет.
- `flake8`: замечаний нет, лимит строки 79 символов.
- `compileall`: файлы компилируются без ошибок.

Тесты интерфейса создают настоящий `Tk`, вызывают команды кнопок и меню,
проверяют содержимое вкладок и жизненный цикл `Toplevel`.
Главное окно не создаётся при импорте модулей, цикл `mainloop` запускается
только в `main.py`.

## Проверка в открытом приложении

| Действие | Наблюдаемый результат |
| --- | --- |
| Нажать «Привет» | `Привет, Илья!` |
| Открыть вкладку «Конвертер» | Видны сумма, списки валют и кнопки |
| Перевести 100 USD в RUB | `100 USD = 9000.00 RUB` |
| Ввести `abc` | Старый результат сразу очищается |
| Нажать Enter для `abc` | Сообщение `Введите сумму от 0, до двух знаков: 123,45.` |
| Восстановить 100, выбрать EUR и перевести в RUB | `100 EUR = 10000.00 RUB`, ошибка очищена |
| Нажать «Показать курсы» | Одновременно видны главное окно и окно курсов |
| Нажать «Закрыть» в окне курсов | Главное окно и расчёт остаются на экране |
| Выбрать File -> Exit | Процесс завершился с кодом 0, окон приложения не осталось |
