## Запуск

Нужны Python 3.10 или новее и Tkinter с Tcl/Tk. Сторонние библиотеки для
запуска не требуются. Команды выполняются из корня репозитория:

```bash
git clone https://github.com/EnroXD1/mtp-lab5-variant5.git
cd mtp-lab5-variant5
python main.py
```

На Windows также можно использовать `py -3 main.py`. Проверка установки
Tkinter: `python -m tkinter` должна открыть демонстрационное окно.
Если компонент отсутствует, установите Python с поддержкой Tcl/Tk.

## Проверка вручную

1. На вкладке «Приветствие» нажмите «Привет». Для имени `Илья` появится
   `Привет, Илья!`, для пустого имени - `Привет!`.
2. Откройте «Конвертер», оставьте `100`, `USD`, `RUB` и нажмите «Перевести».
   Результат: `100 USD = 9000.00 RUB`. В поле суммы работает и Enter.
3. Введите `abc` и нажмите Enter: появится сообщение об ошибке. При изменении
   суммы или валют старый результат очищается.
4. Нажмите «Показать курсы»: откроется отдельное окно. Его можно закрыть,
   продолжить расчёты и открыть снова. Повторное открытие не создаёт копий.
5. Выберите `File -> Exit`: главное и дополнительное окна закроются.

Курсы фиксированные и учебные: `1 USD = 90 RUB`, `1 EUR = 100 RUB`.
Это не актуальные рыночные данные. Интернет для работы не нужен.
Сумма от 0 до 1 000 000 000, максимум два знака после точки или запятой.
Отрицательные числа, экспоненциальная запись, NaN и бесконечность отклоняются.
Расчёт выполняется через RUB с `Decimal`, округление до двух знаков -
`ROUND_HALF_UP`. Поддерживаются RUB, USD и EUR, в том числе пересчёт между
одинаковыми валютами.

## Тесты

```bash
python -X utf8 -m unittest discover -s tests -v
python -m compileall -q lab5 main.py tests
python -m pip install -r requirements-dev.txt
python -m flake8 lab5 main.py tests
```

Всего 31 тест: 15 проверяют расчёты и валидацию, 16 работают с настоящими
виджетами Tkinter. Для тестов интерфейса нужна графическая среда.
[GitHub Actions](https://github.com/EnroXD1/mtp-lab5-variant5/actions) запускает
те же проверки на Windows с Python 3.10 и 3.13.
